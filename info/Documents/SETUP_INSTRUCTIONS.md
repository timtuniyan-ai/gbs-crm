# Инструкция по настройке системы загрузки документов

## Шаг 1: Создание Storage Bucket в Supabase

1. Откройте Supabase Dashboard
2. Перейдите в раздел **Storage**
3. Нажмите **Create bucket**
4. Заполните данные:
   - **Bucket Name**: `crm.gbs`
   - **Public bucket**: ✓ (включите для публичного доступа к файлам)
5. Нажмите **Create bucket**

## Шаг 2: Выполнение SQL скрипта

1. Откройте Supabase Dashboard
2. Перейдите в раздел **SQL Editor**
3. Создайте новый запрос
4. Скопируйте и выполните содержимое файла `src/database/documents_setup.sql`
5. Убедитесь, что все запросы выполнены успешно

## Шаг 3: Проверка настройки

### Проверка таблицы
```sql
SELECT * FROM crm_gbs_documents LIMIT 1;
```

### Проверка Storage Bucket
1. Перейдите в **Storage** → **crm.gbs**
2. Убедитесь, что bucket создан и публичный

### Проверка политик
```sql
-- Проверка RLS для таблицы
SELECT * FROM pg_policies WHERE tablename = 'crm_gbs_documents';

-- Проверка политик Storage
SELECT * FROM storage.policies WHERE bucket_id = 'crm.gbs';
```

## Шаг 4: Тестирование

1. Запустите приложение
2. Откройте карточку клиента
3. Перейдите на таб **Documents**
4. Попробуйте загрузить тестовый файл
5. Проверьте, что файл отображается в списке
6. Попробуйте скачать и удалить файл

## Возможные проблемы

### Ошибка "Policy violation"
**Решение**: Убедитесь, что RLS политики настроены правильно. Выполните скрипт из `documents_setup.sql` еще раз.

### Файл не загружается
**Решение**: 
- Проверьте, что bucket `crm.gbs` создан
- Проверьте, что bucket публичный
- Проверьте размер файла (максимум 50MB для Free tier)

### Файл загружается, но не отображается
**Решение**: Проверьте, что в таблице `crm_gbs_documents` есть запись о файле:
```sql
SELECT * FROM crm_gbs_documents ORDER BY created_at DESC LIMIT 5;
```

## Структура хранения файлов

Файлы хранятся в следующей структуре:
```
crm.gbs/
└── documents/
    ├── john-doe/
    │   ├── 2024-11-25T10-30-00-000Z-contract.pdf
    │   └── 2024-11-25T11-15-00-000Z-invoice.xlsx
    └── acme-corp/
        └── 2024-11-25T09-00-00-000Z-proposal.pdf
```

Имя папки формируется из имени клиента (firstName + lastName) или названия компании (businessName).

## Поддерживаемые форматы файлов

- Документы: `.pdf`, `.doc`, `.docx`, `.txt`
- Таблицы: `.xls`, `.xlsx`
- Презентации: `.ppt`, `.pptx`
- Изображения: `.jpg`, `.jpeg`, `.png`, `.gif`

## Ограничения

- Максимальный размер файла: **50MB** (Free tier)
- Для увеличения лимита перейдите на Pro tier (до 5GB)
