# Глобальные заметки CRM - Инструкция по установке

## Описание функционала

Глобальные заметки - это заметки, которые не привязаны к конкретным клиентам и доступны из любого места CRM системы.

### Основные возможности:
- **Боковая панель слева** - выезжает при клике на кнопку "Notes"
- **Добавление заметок** - с названием и текстом
- **Копирование в буфер** - клик на название заметки копирует текст в буфер обмена и автоматически закрывает панель
- **Редактирование** - возможность изменить название и текст
- **Удаление** - удаление ненужных заметок
- **Автоматическое закрытие** - панель закрывается после копирования текста

## Установка

### Шаг 1: Обновление базы данных

Выполните SQL-скрипт в Supabase SQL Editor:

```bash
# Откройте файл: info/Documents/global_notes_migration.sql
# Скопируйте содержимое и выполните в Supabase SQL Editor
```

Или выполните команды вручную:
1. Откройте Supabase Dashboard
2. Перейдите в SQL Editor
3. Вставьте содержимое файла `global_notes_migration.sql`
4. Нажмите "Run"

### Шаг 2: Проверка установки

После выполнения SQL-скрипта проверьте:
1. Таблица `gbs_crm_global_notes` создана
2. Индексы созданы
3. RLS политики активны

### Шаг 3: Деплой приложения

```bash
# Соберите проект
npm run build

# Задеплойте на сервер
# (используйте ваш обычный процесс деплоя)
```

## Использование

### Открытие панели заметок
1. На левом краю экрана находится кнопка с иконкой заметки
2. Нажмите на неё - панель выедет слева
3. Весь контент CRM сдвинется вправо

### Добавление заметки
1. Нажмите кнопку "Добавить заметку"
2. Введите название заметки
3. Введите текст заметки
4. Нажмите "Добавить"

### Копирование текста заметки
1. В списке заметок нажмите на название нужной заметки
2. Текст заметки (без названия) скопируется в буфер обмена
3. Панель автоматически закроется
4. Вставьте текст куда нужно (Ctrl+V / Cmd+V)

### Редактирование заметки
1. Нажмите на иконку карандаша рядом с заметкой
2. Измените название и/или текст
3. Нажмите "Сохранить"

### Удаление заметки
1. Нажмите на иконку корзины рядом с заметкой
2. Заметка будет удалена

### Закрытие панели
1. Нажмите на крестик в правом верхнем углу панели
2. Или нажмите на кнопку "Notes" на левом краю экрана
3. Или просто кликните на название заметки (автоматически закроется после копирования)

## Технические детали

### Созданные файлы:
- `src/types/index.ts` - добавлен интерфейс `GlobalNote`
- `src/hooks/useGlobalNotes.ts` - хук для работы с API глобальных заметок
- `src/components/GlobalNotesPanel.tsx` - компонент боковой панели
- `src/components/Dashboard.tsx` - интегрирована кнопка и панель
- `src/App.tsx` - подключен хук useGlobalNotes
- `src/database_setup.sql` - обновлен основной скрипт БД
- `info/Documents/global_notes_migration.sql` - миграция для существующих БД

### База данных:
- Таблица: `gbs_crm_global_notes`
- Поля: `id`, `title`, `content`, `created_at`, `updated_at`, `user_id`
- RLS: включен, пользователи видят только свои заметки
- Индексы: по `user_id` и `created_at`

### Стилизация:
- Использует Tailwind CSS v4
- Компоненты shadcn/ui
- Анимация выезда панели (300ms)
- Адаптивный дизайн

## Возможные проблемы

### Панель не открывается
- Проверьте консоль браузера на ошибки
- Убедитесь, что миграция БД выполнена

### Заметки не сохраняются
- Проверьте RLS политики в Supabase
- Убедитесь, что пользователь авторизован

### Текст не копируется
- Проверьте разрешения браузера на доступ к буферу обмена
- Используйте HTTPS (для production)

## Поддержка

При возникновении проблем проверьте:
1. Логи Supabase
2. Консоль браузера
3. Network tab в DevTools
