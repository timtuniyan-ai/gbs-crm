## 📊 Структура базы данных

### Таблицы

#### 1. clients (16 полей)
Основная информация о клиентах:
- `id` - UUID, primary key
- `first_name`, `last_name` - Имя и фамилия
- `phone`, `email` - Контакты
- `business_name` - Название бизнеса
- `credit_score` - Кредитный рейтинг
- `industry` - Индустрия
- `date_organized` - Дата организации компании
- `estimated_yearly_revenue` - Годовой доход
- `estimated_monthly_revenue` - Месячный доход
- `project_type` - Тип проекта
- `budget` - Бюджет
- `budget_purpose` - Цель бюджета
- `lead_source` - Источник лида
- `description_notes` - Дополнительные заметки
- `archived` - Статус архивации
- `created_at`, `updated_at` - Timestamp поля
- `user_id` - Связь с пользователем (auth.users)

#### 2. notes (6 полей)
Заметки для клиентов:
- `id` - UUID, primary key
- `client_id` - Foreign key к clients
- `content` - Текст заметки
- `created_at` - Дата создания
- `updated_at` - Дата обновления
- `user_id` - Связь с пользователем

#### 3. tasks (10 полей)
Задачи для клиентов:
- `id` - UUID, primary key
- `client_id` - Foreign key к clients
- `title` - Заголовок задачи
- `description` - Описание
- `status` - Статус ('in-progress', 'completed')
- `priority` - Приоритет ('low', 'medium', 'high')
- `due_date` - Срок выполнения
- `created_at` - Дата создания
- `updated_at` - Дата обновления
- `user_id` - Связь с пользователем

### Безопасность

- ✅ Row Level Security (RLS) на всех таблицах
- ✅ Пользователи видят только свои данные
- ✅ Cascade deletion для целостности данных
- ✅ Foreign key ограничения
- ✅ CHECK constraints для валидации

### Производительность

- ✅ 9 индексов для оптимизации запросов
- ✅ Автоматическое обновление timestamp через триггеры
- ✅ Эффективные foreign key связи

## 🔄 Этапы миграции

### Этап 1: Настройка БД (15-20 минут)
1. Создать проект в Supabase
2. Запустить SQL скрипт из `database_setup.sql`
3. Проверить таблицы, индексы, триггеры, RLS
4. Создать тестового пользователя
5. Протестировать RLS политики

### Этап 2: Интеграция кода (30-45 минут)
1. Установить @supabase/supabase-js
2. Создать .env с credentials
3. Создать /lib/supabase.ts
4. Создать /lib/database.types.ts
5. Создать /lib/api.ts
6. Обновить App.tsx
7. Обновить LoginForm.tsx

### Этап 3: Тестирование (20-30 минут)
1. Регистрация пользователя
2. Вход/выход
3. CRUD операции с клиентами
4. CRUD операции с заметками
5. CRUD операции с задачами
6. Поиск
7. Архивирование
8. Проверка RLS

### Этап 4: Деплой (15-20 минут)
1. Билд приложения
2. Тест билда локально
3. Деплой на хостинг
4. Настройка env переменных
